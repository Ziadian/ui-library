## ◇ Overview

**XDFLEX UI** is a customized interface layer for **XDFLEX HUB**, built on top of the open-source **Cascade UI** project.

It keeps Cascade’s macOS-inspired foundation while extending and adapting the interface for XDFLEX HUB — including its component behavior, workflow-oriented layouts, multi-select controls, styling, and hub-specific presentation.

This repository serves as the source home for the XDFLEX-maintained Cascade build used by **XDFLEX HUB**.

</div>

## ✦ Highlights

> **Clean hierarchy**  
> Information is grouped into predictable sections so large automation hubs remain readable.

> **Reusable components**  
> Controls share the same visual language across every XDFLEX HUB module.

> **Multi-select support**  
> Dropdown behavior is tuned for more complex option sets and automation workflows.

> **Responsive structure**  
> Built around layouts that can adapt across different window sizes.

> **Source-first**  
> The UI remains readable and maintainable instead of being treated as a black-box build.
